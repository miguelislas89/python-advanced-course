# Módulo 1: Entorno y Herramientas

Entorno de desarrollo configurado bajo estándares estrictos de grado de producción.

## Stack Utilizado
- **Gestor de Dependencias:** Poetry (`pyproject.toml`)
- **Estilo de Código:** PEP 8 / PEP 20
- **Formateadores Automatizados:** Black e Isort
- **Análisis Estático (Linter):** Ruff (Engine en Rust)
- **Automatización Local:** Git Pre-commit Hooks
