# Curso Avanzado de Python y Spark

Repositorio oficial para el desarrollo e implementación de los laboratorios modulares del programa avanzado de ingeniería de software y Big Data.

## 🛠️ Estructura del Proyecto
- `01_fundamental/`: Laboratorios de core del lenguaje, funciones y buenas prácticas.
- `02_intermediate/`: Testing automatizado, asincronismo y persistencia.
- `03_advanced/`: Ingeniería de datos distribuida (PySpark) y despliegues en la nube (GCP).
